## codex

**メインCLIインターフェース**

Codexエージェントのメインエントリポイントとして機能する統合コマンドラインツールです。

### 主な機能：
- **対話的モード**: サブコマンドが指定されない場合、TUIインターフェースが起動
- **非対話的実行**: `exec`サブコマンドによる自動実行
- **認証管理**: ログイン・ログアウト機能
- **MCPサーバー**: Model Context Protocol（MCP）サーバーとして動作
- **プロトコル通信**: stdin/stdout経由でのプロトコル通信
- **シェル補完**: Bash等のシェル補完スクリプト生成
- **デバッグ機能**: SeatbeltやLandlockを使ったサンドボックス実行
- **パッチ適用**: Gitパッチの適用機能
- **TypeScript生成**: プロトコル用TypeScriptバインディング生成

### 実行例：
```bash
# 対話的モードで起動
cargo run --bin codex

# 非対話的モードで実行
cargo run --bin codex exec "ファイルを作成してください"

# ログイン
cargo run --bin codex login

# MCPサーバーとして起動
cargo run --bin codex mcp
```

## apply_patch

**パッチ適用ツール**

Codexエージェントが生成したdiff（差分）をローカルのワーキングツリーに`git apply`として適用するためのツールです。

### 主な機能：
- Codexエージェントが生成した最新のdiffを自動適用
- Gitワーキングツリーとの統合
- パッチ適用の安全性確保

### 実行例：
```bash
cargo run --bin apply_patch
```

## codex-execpolicy

**コマンド実行ポリシー検証ツール**

実行されるコマンドがセキュリティポリシーに準拠しているかを検証するためのツールです。

### 主な機能：
- **コマンド安全性検証**: 実行予定のコマンドの安全性をポリシーファイルに基づいて判定
- **JSONサポート**: コマンド情報をJSON形式で受け取り処理
- **ポリシーファイル**: カスタムポリシーファイルの指定に対応
- **詳細レポート**: 検証結果を詳細なJSONレポートとして出力

### 検証結果の種類：
- **Safe**: コマンドは完全に安全
- **Match**: ポリシーにマッチするが、ファイル書き込みの可能性あり
- **Forbidden**: ポリシーにより実行が禁止されているコマンド
- **Unverified**: 安全性を検証できないコマンド

### 実行例：
```bash
# コマンドの安全性を検証
cargo run --bin codex-execpolicy check ls -la

# JSON形式でコマンド情報を検証
cargo run --bin codex-execpolicy check-json '{"program": "git", "args": ["status"]}'

# カスタムポリシーファイルを使用
cargo run --bin codex-execpolicy -p custom-policy.toml check npm install
```

## codex-file-search

**高速ファイル検索ツール**

プロジェクト内のファイルを高速で検索するためのツールです。ファジーマッチング機能を提供します。

### 主な機能：
- **ファジーマッチング**: あいまい検索でファイル名を検索
- **JSON出力**: 検索結果をJSON形式で出力
- **ハイライト表示**: ターミナル上でマッチした文字をハイライト表示
- **インデックス計算**: マッチ位置のインデックス情報を提供
- **結果制限**: 大量の結果に対する制限機能

### 実行例：
```bash
# ファイルを検索
cargo run --bin codex-file-search "main.rs"

# JSON形式で出力
cargo run --bin codex-file-search --json "config"

# マッチ位置をハイライト表示
cargo run --bin codex-file-search --compute-indices "test"
```

## codex-linux-sandbox

**Linux サンドボックス実行環境**

Linuxにおいて、コマンドを安全なサンドボックス環境内で実行するためのツールです。Landlockとseccompを使用してセキュリティを確保します。

### 主な機能：
- **Landlock統合**: Linuxカーネルのセキュリティモジュール使用
- **seccomp フィルタ**: システムコール制限
- **安全な実行環境**: 制限された環境でのコマンド実行
- **execv呼び出し**: 最終的にexecvシステムコールでコマンド実行

### セキュリティ機能：
- ファイルシステムアクセス制御
- システムコール制限
- ネットワークアクセス制御

### 実行例：
```bash
cargo run --bin codex-linux-sandbox -- /bin/ls /home/user
```

## codex-mcp-client

**MCP クライアントテストツール**

Model Context Protocol（MCP）サーバーとの通信をテストするためのシンプルなクライアントツールです。

### 主な機能：
- **MCP サーバー接続**: 指定されたMCPサーバーに接続
- **初期化処理**: MCPプロトコルの初期化手順を実行
- **ツールリスト取得**: サーバーが提供するツール一覧を取得
- **JSON出力**: レスポンスを整形されたJSONで表示
- **デバッグログ**: 詳細なデバッグ情報を出力

### 実行例：
```bash
# MCPサーバーに接続してツール一覧を取得
cargo run --bin codex-mcp-client codex-mcp-server

# 追加引数付きでMCPサーバーを起動
cargo run --bin codex-mcp-client my-mcp-server --config config.json
```

## codex-protocol-ts

**TypeScript バインディング生成ツール**

CodexプロトコルのTypeScriptバインディングファイルを生成するためのツールです。

### 主な機能：
- **TypeScript生成**: RustのプロトコルコードからTypeScriptファイルを自動生成
- **Prettier統合**: 生成されたファイルを自動的にフォーマット
- **出力ディレクトリ指定**: 生成ファイルの保存先を指定可能

### 実行例：
```bash
# TypeScriptファイルを生成
cargo run --bin codex-protocol-ts -o ./generated

# Prettierでフォーマットしながら生成
cargo run --bin codex-protocol-ts -o ./generated -p prettier
```

## 実行方法

各バイナリを実行するには、以下のコマンド形式を使用してください：

```bash
# 基本的な実行方法
cargo run --bin <バイナリ名>

# 引数付きで実行
cargo run --bin <バイナリ名> -- <引数1> <引数2> ...

# ヘルプの表示
cargo run --bin <バイナリ名> -- --help
```

### 使用例：
```bash
# メインCLIを起動
cargo run --bin codex

# ファイル検索を実行
cargo run --bin codex-file-search -- "*.rs"

# 非対話的モードでタスクを実行
cargo run --bin codex-exec -- "README.mdを作成してください"
```
