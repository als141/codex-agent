## 概要

Codex-CLIは、構造化されたメッセージシステムを通じてユーザーとアシスタント間の対話を管理しています。このシステムは、リアルタイムストリーミング、ツール統合、推論過程の可視化、永続的履歴管理を統合的に処理します。

### アーキテクチャの特徴
- **型安全なメッセージ構造**: Rust型システムによる厳密な検証
- **ストリーミング対応**: リアルタイム応答とデルタ更新
- **マルチモーダル対応**: テキスト、画像、ツール実行結果の統合
- **履歴永続化**: セッション跨ぎの状態保持

pub(crate) struct ConversationHistory {

impl ConversationHistory {
    /// `items` is ordered from oldest to newest.
    pub(crate) fn record_items<I>(&mut self, items: I)
    where
        I: IntoIterator,
        I::Item: std::ops::Deref<Target = ResponseItem>,

            }

### 履歴圧縮機能

**最新N件のメッセージ保持** (35-61行)
```rust
pub(crate) fn keep_last_messages(&mut self, n: usize) {
    if n == 0 {
        self.items.clear();
        return;
    }

    // Collect the last N message items (assistant/user), newest to oldest.
    let mut kept: Vec<ResponseItem> = Vec::with_capacity(n);
    for item in self.items.iter().rev() {
        if let ResponseItem::Message { role, content, .. } = item {
            kept.push(ResponseItem::Message {
                // we need to remove the id or the model will complain
                id: None,
                role: role.clone(),
                content: content.clone(),
            });
            if kept.len() == n {
                break;
            }
        }
    }

    // Preserve chronological order (oldest to newest) within the kept slice.
    kept.reverse();
    self.items = kept;
}
```

```rust
impl From<Vec<InputItem>> for ResponseInputItem {
    fn from(items: Vec<InputItem>) -> Self {
        Self::Message {
            role: "user".to_string(),
            content: items
                .into_iter()
                .filter_map(|c| match c {
                    InputItem::Text { text } => Some(ContentItem::InputText { text }),
                    InputItem::Image { image_url } => Some(ContentItem::InputImage { image_url }),
                    InputItem::LocalImage { path } => {
                        // Base64エンコードによる画像処理
                        match std::fs::read(&path) {
                            Ok(bytes) => {
                                let mime = mime_guess::from_path(&path)
                                    .first()
                                    .map(|m| m.essence_str().to_owned())
                                    .unwrap_or_else(|| "application/octet-stream".to_string());
                                let encoded = base64::engine::general_purpose::STANDARD.encode(bytes);
                                Some(ContentItem::InputImage {
                                    image_url: format!("data:{mime};base64,{encoded}"),
                                })
                            }
                            Err(err) => {
                                tracing::warn!("Skipping image {} – could not read file: {}", 
                                             path.display(), err);
                                None
                            }
                        }
                    }
                })
                .collect::<Vec<ContentItem>>(),
        }
    }
}
```

## まとめ

Codex-CLIのユーザー/アシスタントプロンプト管理システムは、以下の特徴により高度な対話体験を実現しています：

**技術的優位性**
- **型安全性**: Rustの型システムによる堅牢なデータ管理
- **リアルタイム性**: ストリーミングベースの即座な応答
- **マルチモーダル**: テキスト・画像・ツール結果の統合処理
- **永続化**: セッション跨ぎの状態保持と履歴管理

**拡張性**
- **プラガブル設計**: 新しいコンテンツタイプやツールへの対応
- **階層化アーキテクチャ**: レイヤー別の責任分離
- **設定駆動**: 利用環境に応じた柔軟な調整

**実用性**
- **効率的履歴管理**: 適応的圧縮と高速検索
- **安全な永続化**: ファイルロックによる整合性保証
- **デバッグ支援**: 詳細なログとトレーシング

この実装により、Codex-CLIは複雑な対話フローを透明性と効率性を両立させながら処理し、高品質なAIエージェント体験を提供しています。
